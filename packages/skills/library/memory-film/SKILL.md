# memory-film

A film about people rather than about events: an anniversary, a wedding, a year.

## What it changes

- **Feeling is almost the whole ranking.** Information density is weighted at
  0.05, which is as close to "ignore it" as the scale allows. Nobody re-watches
  a memory film to learn something.
- **Nothing is rushed.** Anything with real feeling in it gets three seconds
  minimum, is never cut into, and keeps the reaction that follows.
- **The ending is thirty percent of the running time.** This is the one style
  where a long, slow close is correct rather than indulgent.
- **Dissolves between chapters**, hard cuts within them.

## A note on people

The `faces-over-places` rule matches the person ids `me`, `partner` and
`family`. Those come from the project background, so edit the rule to match the
ids you actually used — or add your own.
