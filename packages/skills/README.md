# @editorial-ir/skills

What counts as a good edit.

A skill never looks at video. The decision layer says a moment scores 0.91 on emotional intensity; a skill says what to do about it. Change the model and the style survives; change the style and the analysis survives.

Rules are data, and the six shipped skills live as YAML next to a README in [`library/`](./library) — copy one, change three numbers, and it is yours.
