# @editorial-ir/cli

`oea`.

The verbs follow the shape of the pipeline, because that is what a user has to
understand anyway: register media, say what it is, compile it, look at what it
understood, plan a cut, send it somewhere.

```bash
oea demo ./demo    # the whole thing, on a worked example, with nothing installed
oea --help
```

Keys are read from the environment and never from flags: a key in shell history
is a key in a backup.

See the [README](../../README.md) for the walkthrough.
